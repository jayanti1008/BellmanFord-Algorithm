# Bellman-Ford Shortest Path Algorithm

## Mini Project – Design and Analysis of Algorithms

### Project Title
Implementation and Performance Analysis of Bellman-Ford Shortest Path Algorithm using Graph Data Structures

---

## Description
This project implements the Bellman-Ford Algorithm in C programming language to compute the shortest path from a source vertex to all other vertices in a weighted graph.

The implementation supports both directed and undirected weighted graphs through a user-interactive menu-driven system. The algorithm is also capable of detecting negative weight cycles, making it highly useful in network routing and graph-based applications.

---

## Features
- Shortest path computation
- Directed and undirected graph support
- Negative edge weight handling
- Negative weight cycle detection
- Menu-driven interactive interface
- Graph representation using structures
